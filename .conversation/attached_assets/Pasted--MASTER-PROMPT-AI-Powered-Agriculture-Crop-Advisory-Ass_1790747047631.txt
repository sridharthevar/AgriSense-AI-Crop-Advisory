## 3. Product Goal

Build a polished, mobile-responsive, professional SaaS platform that enables authenticated users to:

- Create and manage farm profiles (location, soil type, climate zone, crop history)
- Submit detailed crop advisory requests (current crop, growth stage, observed symptoms, soil test data, weather conditions)
- Receive structured, actionable AI-generated advisory reports powered by Google Gemini
- View historical advisories, track outcomes, and receive follow-up recommendations
- Access a dashboard with farm health overview, recent advisories, and seasonal alerts
- Support multi-language output (English + Hindi) for Indian farmers

The final deliverable must be a fully working application that a developer can run with `npm install && npm run dev` and immediately use.

## 4. Mandatory Features

- Email/password registration and login using secure JWT + bcrypt
- Protected routes on both frontend and backend
- Role support: `farmer`, `agronomist`, `admin` (default = farmer)
- Session persistence with secure HTTP-only cookies or Authorization header

### Farm Management

- Fields: farm name, location (state, district, village), GPS coordinates (optional), soil type, irrigation type, total area (acres/hectares), primary crops, farm notes

  - Diagnosis confidence score
  - Primary & secondary issues
  - Immediate action plan
  - Fertilizer & nutrient recommendation

  - Irrigation schedule
  - Expected outcome & risk factors

### AI Safety & Quality
- Strict JSON schema enforcement on every Gemini response
- Server-side Zod validation of AI output before saving
- Fallback handling if Gemini returns malformed data
- Rate limiting on AI endpoints

### Additional Required Features

- Soft delete for farms and advisories
- Audit timestamps (created_at, updated_at)

## 7. User Flow

1. User lands on marketing page → clicks “Get Started”
2. Registers with name, email, password, preferred language
3. Logs in → redirected to Dashboard
4. Creates first farm (name, location, soil type, irrigation)
5. Clicks “New Advisory” → multi-step form
6. Selects farm → fills crop details, symptoms, soil data
7. Submits → backend calls Gemini with structured prompt
8. AI returns validated JSON → saved to database
9. User sees rich advisory report with action cards
10. Can mark actions as completed and request follow-up advice later

## 10. Database Schema (Production SQL for PostgreSQL)

```sql
-- Enable UUID extension
CREATE EXTENSION IF NOT EXISTS "pgcrypto";

-- Users table
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  full_name TEXT NOT NULL,
  role TEXT NOT NULL DEFAULT 'farmer' CHECK (role IN ('farmer', 'agronomist', 'admin')),
  preferred_language TEXT DEFAULT 'en' CHECK (preferred_language IN ('en', 'hi')),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Farms table
CREATE TABLE farms (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  state TEXT,
  district TEXT,
  village TEXT,
  latitude DECIMAL(9,6),
  longitude DECIMAL(9,6),
  soil_type TEXT,
  irrigation_type TEXT,
  area_value DECIMAL(10,2),
  area_unit TEXT DEFAULT 'acres',
  primary_crops TEXT[],
  notes TEXT,
  is_deleted BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Advisories table
CREATE TABLE advisories (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  farm_id UUID NOT NULL REFERENCES farms(id) ON DELETE CASCADE,
  crop_name TEXT NOT NULL,
  crop_variety TEXT,
  growth_stage TEXT,
  symptoms JSONB,
  soil_data JSONB,
  weather_data JSONB,
  previous_treatments TEXT,
  ai_raw_response JSONB,
  advisory_report JSONB NOT NULL, -- validated structured output
  status TEXT DEFAULT 'completed' CHECK (status IN ('pending', 'completed', 'follow_up_required')),
  confidence_score DECIMAL(3,2),
  language TEXT DEFAULT 'en',
  is_deleted BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Indexes
CREATE INDEX idx_farms_user_id ON farms(user_id);
CREATE INDEX idx_advisories_user_id ON advisories(user_id);
CREATE INDEX idx_advisories_farm_id ON advisories(farm_id);
CREATE INDEX idx_advisories_created_at ON advisories(created_at DESC);
